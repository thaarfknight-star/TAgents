# 🛰 مانیتور شبکه‌ی ایجنت‌های TAgents

برنامه‌ی ویندوز (PyQt6) برای نمایش زنده‌ی «شبکه‌ی عصبی» ایجنت‌ها: هر ایجنت یک نود
است، وضعیت لحظه‌ای‌اش با رنگ مشخص می‌شود، با کلیک روی هر نود می‌بینی الان مشغول
چه کاری است، و با دکمه‌های «توقف کار» / «شروع مجدد» می‌توانی کارش را متوقف یا
از سر بگیری — با گزارش برگشتی.

نودها (۶ عدد): **BabyT** 🧠 (هماهنگ‌کننده، مرکز گراف) + پنج ایجنت main
(TAgent 🎮 و TAgent1 1️⃣ تا TAgent4 4️⃣).

> **محدوده‌ی پوشش:** این برنامه **فقط شبکه‌ی main** (BabyT + پنج ایجنت) را
> مانیتور می‌کند؛ شبکه‌ی work جداست و دست‌نخورده می‌ماند.

## معماری

### ۱. فید وضعیت (نمایش)

فایل `status.json` در ریشه‌ی ریپو هر ~۲ دقیقه توسط BabyT (کرون سمت BabyT)
به‌روز می‌شود. برنامه هر ۱۵ ثانیه آن را از این آدرس می‌خواند:

```
https://raw.githubusercontent.com/thaarfknight-star/TAgents/main/status.json
```

- هیچ داده‌ی «لایو»ی ساخته نمی‌شود؛ اگر فید قدیمی باشد، برنامه برچسب
  «آخرین به‌روزرسانی: X دقیقه پیش» نشان می‌دهد.
- اسکیمای دقیق فید در `status.schema.json` مستند شده است.
- رنگ نودها: 🟢 سبز چشمک‌زن = مشغول به کار | ⚪ خاکستری = بیکار |
  🟡 کهربایی = متوقف‌شده | 🔴 قرمز = خطا

### ۲. حلقه‌ی فرمان (کنترل)

دکمه‌ی «⏸ توقف کار» / «▶ شروع مجدد» یک فایل `inbox/cmd-<epoch>.json` با این
اسکیما از طریق GitHub Contents API می‌سازد:

```json
{"id": "cmd-1728...", "action": "pause", "agent": "tagent", "ts": "2026-10-07T...", "by": "taha"}
```

واچر سمت BabyT پوشه‌ی `inbox` را می‌خواند، کرون‌های آن ایجنت را (طبق نگاشت
`agent-jobs.json`) pause/resume می‌کند و گزارش را در `outbox/rep-<epoch>.json`
می‌گذارد:

```json
{"id": "rep-1728...", "cmd_id": "cmd-1728...", "ok": true, "summary": "...", "details": [], "ts": "2026-10-07T..."}
```

برنامه پوشه‌ی `outbox` را پول می‌کند و گزارش را در لاگ فعالیت + یک دیالوگ
نشان می‌دهد.

## راه‌اندازی توکن

۱. برنامه را اجرا کن و روی «⚙ تنظیمات توکن» بزن.
۲. توکن GitHub با دسترسی `repo` را وارد و ذخیره کن.

توکن فقط روی همین سیستم در `%APPDATA%/TAgents/config.json` ذخیره می‌شود —
**هرگز داخل ریپو قرار نمی‌گیرد.**

## اجرا از سورس

```
pip install -r requirements.txt
python app/main.py
```

## بیلد

با هر پوش به `main`، ورک‌فلوی `.github/workflows/build-windows.yml` به‌صورت
خودکار `TAgents-Monitor.exe` تک‌فایل را با PyInstaller می‌سازد
(artifact با نام `TAgents-Monitor-win`).

## ساختار ریپو

```
app/                  سورس برنامه (main.py, feed.py, commands.py, agent_meta.py)
status.schema.json    اسکیمای فید وضعیت
agent-jobs.json       نگاشت ایجنت → کلیدواژه‌های نام کرون‌ها
inbox/  outbox/       حلقه‌ی فرمان (فایل‌های cmd-* و rep-*)
legacy/v01/           میراث نسخه‌ی ۰.۱ (inbox/outbox/presence قدیمی)
.github/workflows/    بیلد خودکار exe ویندوز
```
